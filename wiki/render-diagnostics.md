# Render diagnostics

What [rendering](render.md) reports as skipped or approximated, and how warnings reach `export`, `inspect` and bundles. Load with `bundle`; the renderer itself is the `render` topic.

REST nodes optionally include `_figlens.renderDiagnostics`: `{nodeId, feature, field, state, reason}` entries for effective visible fills and strokes with saved geometry, including mask paints, with nonzero unsupported image adjustments (contrast, temperature, tint, highlights, shadows), TILE image fills, angular/diamond gradients, paint types it does not draw (anything but solid, image and linear/angular/radial/diamond gradient fills, e.g. Figma's 2026 CUSTOM shader, NOISE and PATTERN fills, VIDEO and EMOJI; reported on strokes too when they have no saved geometry, since such a stroke is still drawn around the box and that paint draws nothing), active background blur (approximate: see the background blur rule in [rendering](render.md)) effect types it does not draw, such as GLASS, and vector-like layers (vector, boolean, star, polygon, ellipse, line) whose `fillGeometry` or `strokeGeometry` is absent, as in a [copied selection](clipboard.md): the fill is drawn as the box and the stroke around it (both `approximate`); an empty saved list is not reported. `field` names the effective Kiwi field, including selected text/vector style overrides; `state` is `skipped` or `approximate`. Hidden/zero-opacity nodes and paints, clipped-away nodes and consumed boolean operands are excluded. This is a bounded list of known renderer limitations, not an exhaustive visual audit or proof of Figma parity. Missing image bytes are reported separately: by bundles as missing assets, and by `export` as one warning per drawn image paint without bytes, used style overrides included.

Collection runs during the existing REST traversal, before `_r` is removed. Stroke geometry is checked at most once per node, only when a visible stroke paint would produce a known warning. It does not re-expand the subtree or change SVG/pixels. `nodes` and bundle `design/nodes.json` retain all collected diagnostics. `inspect` keeps at most 20 per included node; `_figlens.renderDiagnosticsTruncated` and the existing top-level `truncated` flag disclose omissions. Its existing depth/200-node limit still applies, so inspect cannot establish that a whole frame has no warnings. Bundle `warnings` and `context.md` include these rendering limitations, as do `export` warnings (#159); `missing-assets.json` remains exclusively asset failures. A warning names a layer, not how much of it shows in the result. `export --hide ID[,ID]` (MCP `hide`, single exports only) sets those layers inside the exported node to hidden after expansion and renders over the same area, so the two images compare pixel for pixel; its warnings leave out the hidden layers, and it reports `hidden`. Their difference is the layer's effect with everything the renderer composites (blend modes, opacity, masks, clipping, layers above), as figlens draws it (#177). It does not measure the skipped adjustment, which figlens cannot draw: a layer that shows but matches what is beneath it gives no difference, while Figma's adjustment would still change it. An id that is the exported node itself or not inside it is rejected, and so is a mask: its warnings were collected with the mask clipping, so what hiding it uncovers would draw without them. Hiding changes nothing else: auto-layout does not reflow the siblings, a boolean operation keeps its saved shape (hiding an operand draws the same image), and the area stays what the plain export covers. Reading it: changed pixels show where the layer reaches the result, and a large area means the skipped rendering likely matters there, so get Figma's own export. Few or no changed pixels prove nothing about fidelity by themselves; treat the layer as covered only after checking that opaque layers above it hide it. An absent diagnostic is not a fidelity guarantee. Glyph outlines need no local font files, but implementation still needs the named fonts; text overrides may retain saved layout and are not automatically classified as stale.
